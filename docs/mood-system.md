# Mood Systems (भाव और उद्देश्य प्रणाली)
**Project:** BHARTI Modern Code (BMC) v3  
**Creator:** Emperor AD

## 🌐 Overview / परिचय
The 'Mood' component in BMC determines the underlying intent, emotional stance, or grammatical objective of a sentence (e.g., statements, commands, inquiries, or desires).
भारती मॉडर्न कोड (BMC) के अंतर्गत 'Mood' (भाव) घटक यह तय करता है कि वाक्य का मूल उद्देश्य, भाव या व्याकरणिक लक्ष्य क्या है (जैसे- सामान्य कथन, आदेश, प्रश्न या इच्छा)।

---

## ⚙️ Key Operators / मुख्य ऑपरेटर:

1. **Interrogative Engine (`[ki-]` / प्रश्नसूचक ऑपरेटर):**
   - Used alongside WH-categories (`jan`, `vastu`, `jaga`, `tem`, `hetu`, `rit`, `matra`) to frame precise questions.
   - इसका उपयोग सटीक प्रश्न पूछने के लिए WH-कटेगोरियों (`jan`, `vastu`, `jaga`, `tem`, `hetu`, `rit`, `matra`) के साथ किया जाता है।

2. **Intent Modifiers (उद्देश्य संशोधक):**
   - Clearly demarcate whether a sentence is declarative (कथनात्मक), imperative (आदेशात्मक), or interrogative (प्रश्नवाचक).
   - यह स्पष्ट रूप से रेखांकित करते हैं कि वाक्य तथ्यात्मक है, कोई आदेश दे रहा है या प्रश्न पूछ रहा है।
