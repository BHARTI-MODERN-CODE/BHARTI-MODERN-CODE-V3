# System 16: Interjection System (इमोशन/प्रतिक्रिया मार्कर प्रणाली)
**Project:** BHARTI MODERN CODE (BMC) v3  
**Language:** BHARTI (भारती)  
**Creator:** Emperor AD  
**Official Reference:** [Interjection System](https://bharti-modern-code.odoo.com/7-grammer)

---

## 1. Definition (परिभाषा)

**English:** An Interjection in BMC is an independent marker or code placed at the beginning (or at an instantaneous point) of a sentence or statement to express the speaker's immediate mental state, emotion, or reflexive response.
**हिंदी:** BMC में Interjection वह स्वतंत्र मार्कर या कोड है जो किसी वाक्य या कथन के आरंभ में लगकर वक्ता की तात्कालिक मानसिक अवस्था, भावना (Emotion) या सहज प्रतिक्रिया (Reflexive Response) को स्पष्ट करता है।

---

## 2. Category & Purpose (श्रेणी और उद्देश्य)

**English:** Categorized under *Universal Reflexive & Emotional Modifiers*, this minimalist framework uses a strictly controlled set of markers instead of an unorganized crowd of random words, helping humans and AI parsers instantly understand the emotional undertone.
**हिंदी:** इसे *Universal Reflexive & Emotional Modifiers* (सार्वभौमिक भावना और प्रतिक्रिया नियंत्रक) श्रेणी में रखा गया है। यह अनगिनत शब्दों का समूह न होकर केवल 4 निश्चित श्रेणियों में बंटा हुआ एक न्यूनतम (Minimalist) ढांचा है, जो इंसान या AI-पार्सर को कथन के पीछे के भाव को तुरंत समझने में मदद करता है।

---

## 3. The 4 Official Markers (4 आधिकारिक मार्कर)

BMC defines all emotional reflexes using only 4 core markers placed right before the expression:

| Marker | Category / Emotion (श्रेणी / भाव) | Primary Function / मुख्य कार्य |
| :--- | :--- | :--- |
| **`Oh!`** | Positive / Joy / Approval (सकारात्मक प्रतिक्रिया) | Expressing joy, praise, agreement, or approval. (खुशी, प्रशंसा, या सहमति जताना।) |
| **`Uf!`** | Negative / Pain / Dislike (नकारात्मक प्रतिक्रिया) | Expressing pain, fatigue, dislike, or trouble. (दर्द, थकान, नापसंद, या परेशानी जताना।) |
| **`Eh!`** | Surprise / Attention (आश्चर्य / ध्यान खींचना) | Expressing sudden surprise or grabbing attention. (अचानक चौंकने पर या ध्यान खींचने के लिए।) |
| **`Ah!`** | Realization / Relief (समझ / राहत) | Expressing sudden realization, solution, or relief. (उलझन सुलझने, बात समझ आने या राहत पर।) |

---

## 4. Usage Examples (उपयोग के उदाहरण)

- **Positive / सकारात्मक भाव:**  
  `Oh! Satya ha!` $\rightarrow$ वाह! सच है! (खुशी / सहमति)
- **Negative / नकारात्मक भाव:**  
  `Uf! Kam mushkil ha!` $\rightarrow$ उफ्फ! काम मुश्किल है! (थकान / परेशानी)
- **Surprise / आश्चर्य भाव:**  
  `Eh! Tu a gaya?` $\rightarrow$ अरे! तुम आ गए? (चौंकना)
- **Realization / समझ या राहत:**  
  `Ah! Rasta mil gaya!` $\rightarrow$ ओह! रास्ता मिल गया! (राहत / स्पष्टता)

*Note on Mid-Sentence Insertion:* If a sudden emotion or reflex occurs midway through a statement, the marker can be placed right at that point (e.g., `Ram, tum eh! Yeh kya kar rahe ho?`).
