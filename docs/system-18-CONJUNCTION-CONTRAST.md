## 1. System Overview (प्रणाली परिचय)

**English:** This system connects sentences, clauses, objects, and ideas, establishing logical relations between them using 5 core independent operators.
**हिंदी:** यह प्रणाली वाक्यों, उपवाक्यों, वस्तुओं और विचारों को जोड़ने तथा उनके बीच तार्किक संबंध (Logical Relations) स्थापित करने के लिए बनाई गई है। इसमें कुल 5 मुख्य स्वतंत्र ऑपरेटर हैं।

---

## 2. Core Operators (5 मुख्य ऑपरेटर)

### 1. `aur` — Addition / AND (जोड़ / और)
- **Function / कार्य:** Connects two or more objects, people, facts, or ideas together. Does not express choice or contrast. (दो या अधिक वस्तुओं, व्यक्तियों, जानकारियों या विचारों को एक साथ जोड़ना।)
- *Example:* `"Ram aur Shyam"` (राम और श्याम)

### 2. `ya` — Alternative / OR (विकल्प / या)
- **Function / कार्य:** Presents an alternative or choice between two or more options. (दो या अधिक विकल्पों में से चुनाव प्रस्तुत करना।)
- *Example:* `"Chai ya pani"` (चाय या पानी)

### 3. `bat` — Contrast / Correction / Differentiation (विरोध / सुधार / अंतर)
- **Function / कार्य:** Single unified operator used for three logical relations based on context:
  - **A. Contrast (विरोध):** Opposite expectation. (*e.g.,* `"Vah garib hai bat imandar hai."` $\rightarrow$ वह गरीब है पर ईमानदार है।)
  - **B. Correction (सुधार):** Amendment/revision. (*e.g.,* `"Ram nahin, bat Shyam aaya."` $\rightarrow$ राम नहीं, बल्कि श्याम आया।)
  - **C. Differentiation (अंतर):** Distinction between states/ideas.
- **Rule / नियम:** No separate operators will be created for these three functions in the future; `bat` handles all three. (भविष्य में इन तीनों कार्यों के लिए अलग-अलग ऑपरेटर नहीं बनाए जाएँगे।)

### 4. `ydi` — Condition / IF (शर्त / यदि)
- **Function / कार्य:** Introduces a condition for an event or action and starts the conditional structure. (किसी घटना या क्रिया के लिए शर्त प्रस्तुत करना और Conditional Structure प्रारंभ करना।)

### 5. `den` — Implication / Result / THEN (परिणाम / तो)
- **Function / कार्य:** Marks the result clause in a conditional structure (`ydi A den B`) or expresses a general result/consequence. (Conditional Structure में शर्त का परिणाम बताना तथा सामान्य परिणाम व्यक्त करना।)
