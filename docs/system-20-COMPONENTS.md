## 1. Agent (कर्ता / कार्य करने वाला)

**English:** An Agent in BMC is the logical component that actually performs or executes an action in a sentence. It operates as an independent action-executing unit within the sentence structure, entirely free from gender, number, or inflection changes (Zero-Exception Structure).
**हिंदी:** Agent वह तार्किक घटक है जो वाक्य में किसी कार्य (Action) को वास्तव में संपादित या निष्पादित करता है। यह जरूरी नहीं है कि Agent हमेशा पारंपरिक व्याकरण वाला 'Subject' ही हो; यह वाक्य की संरचना में एक स्वतंत्र कार्य-निष्पादक इकाई के रूप में काम करता है और किसी भी रूप-परिवर्तन से मुक्त रहता है।

---

## 2. Object (लक्ष्य)

**English:** An Object in BMC is the conceptual, physical, or fictional endpoint/target toward which the verb's action is directed, or which the Subject acts to achieve. According to BMC's fixed word order, it sits between the Subject and the Verb:
**हिंदी:** Object वह वैचारिक, भौतिक या कल्पित अंतिम बिंदु (Endpoint / Target) है जिसकी ओर वाक्य की क्रिया निर्देशित होती है। BMC के निश्चित वाक्य-क्रम के अनुसार यह हमेशा Subject और Verb के बीच बैठता है:

```text
[Subject] + [Object / लक्ष्य] + [Verb / क्रिया]
