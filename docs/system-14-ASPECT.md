# System 14: Aspect System (पहल / स्थिति प्रणाली)
**Project:** BHARTI MODERN CODE (BMC) v3  
**Language:** BHARTI (भारती)  
**Creator:** Emperor AD  
**Official Reference:** [Aspect System](https://bharti-modern-code.odoo.com/9-grammar)

---

## 1. Aspect Markers — State or Nature of Action (काम की स्थिति या प्रकृति)

**English:** Aspect markers express the state or nature of an action in BHARTI.
**हिंदी:** BHARTI में Aspect markers किसी काम की स्थिति या प्रकृति को व्यक्त करते हैं।

| Marker | Meaning / अर्थ |
| :--- | :--- |
| `"tqa"` | Simple (सामान्य) |
| `"ra"` | Continuous (जारी) |
| `"cuka"` | Perfect (पूर्ण) |

---

## 2. Continuous with Time Duration (समय की अवधि के साथ Continuous)

**English:** Rule: No separate aspect marker is created solely to indicate the duration of an action. If an action started in the past and is still ongoing, `"ra"` is used to express continuity. How long the action has been ongoing is indicated by time-indicating words or phrases.
**हिंदी:** नियम: केवल किसी काम की अवधि बताने के लिए अलग Aspect Marker नहीं बनाया जाएगा। यदि कोई काम पहले शुरू हुआ और अभी भी जारी है, तो Continuous को व्यक्त करने के लिए `"ra"` का उपयोग किया जाएगा। काम कितनी देर से जारी है, यह समय-सूचक शब्द या वाक्यांश से स्पष्ट किया जाएगा।

### Examples / उदाहरण:
- मैं पढ़ रहा हूँ।
- मैं दो घंटे से पढ़ रहा हूँ।
- वह सुबह से काम कर रहा है।
- वे तीन दिनों से वहाँ रह रहे हैं।
